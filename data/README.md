# Data

`telco_churn.csv`: 5,986 telecom customers, 21 columns (demographics, subscribed services,
contract and billing details, and the `Churn` label). It is a sample of IBM's public
**Telco Customer Churn** dataset, also available on
[Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn).
The first unnamed column is a row index from the original file and is dropped on load.
